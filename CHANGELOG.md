# Changelog

## 1.0.0

- First public release of Mordheim Optimizer.
- Added an independent English Mordheim knowledge base covering 49 warbands and 318 profiles.
- Added canonical warband, warrior, weapon, armour, equipment, skill, poison, material, and preparation filtering.
- Added configurable candidates, weighted random opponents, and manually configured opponents.
- Added weapon, equipment, and multi-advance Monte Carlo comparisons with cancellable runs.
- Added optional house rules, cost-aware MOTTA ranking, and reusable Excel workbooks.
- Added concise rules-focused tooltips for every visible weapon and armour option.
- Added a compiled Cython combat kernel to the portable Windows executable.
